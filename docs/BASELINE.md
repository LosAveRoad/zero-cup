# 可运行基础版

此版本先提供可操作的集成起点，再拆分增量任务。启动、验证和AI执行规范见 [contribute.md](../contribute.md)。

## 已接通

二维轮廓点拖动与八截面半径滑块控制真实 LatheGeometry，轮廓用受约束单调样条采样且不过冲；3D Raycaster 表面笔划，用**方位角**得到连续 u，跨 U 接缝不再画出贯穿贴图的长线；2048 CanvasTexture 分为**陶瓷底色层**与**墨迹层**，橡皮擦用 `destination-out` 只擦纹样、不擦底色；画笔/橡皮擦/印章三档互斥工具，印章为三款程序化矢量纹样（无图片资产、无黑框），缩放与旋转只作用于下一枚印章；纹理更新按动画帧合并，墨层增量追加而不重放整段历史；最近20步撤销重做且完整历史保留；2.5 秒窑火曲线连续插值素坯→白釉的 PBR 材质与光位；四个推荐机位与 1080×1080 成品 PNG（名称、日期、印章）；IndexedDB v2 作品库保存器型/全部命令/2048 纹理/成品图，v1 存档读取时迁移，损坏记录隔离不阻塞画廊。

在此之上的增量：首屏卷轴序幕（`?prologue=skip` 可跳过）；导入图片后用 Sobel 边缘、非极大值抑制与折线简化提取轮廓，作为 `custom:` 印章拓印上瓶；1/2/4/6/8 重对称旋绘、旋坯弦纹一笔成环、三套程序化名品快绘；外壁单面渲染加带口沿唇边的实体胎壁与洁净内壁；四款名窑釉彩（枢府甜白/汝窑天青/哥窑金丝开片/宫廷描金）、三套展厅灯光与窑温遥测曲线；成品阶段轻叩瓷身按五声调式奏响单音。釉彩与灯光随作品保存，重开时恢复。

## 明确的简化

- 轮廓固定 8 个控制点、只比较半径；胎壁厚度、内壁与口沿唇边按固定 0.036 缩放单位生成，不可调。
- 彩绘只有三档工具与三种蓝色；有重对称、弦纹与轮廓拓印，但没有自由图层、笔刷纹理、笔压与自定义调色板。
- 烧制是曲线插值的 PBR 参数与光位，没有真实窑炉模拟；哥窑开片是确定性的程序化网格，不是随机的物理裂纹，釉面流淌与环境反射探针同样未实现。
- 机位是三个预设加自由轨道，没有景深、背景幕布与打光台。
- 存储为 `StudioArtwork version:2`，数据库 `porcelain-tales-studio/artworks`；不是PRD目标ArtworkMetadata。`glazeFinish`/`lightPreset` 是可选字段，旧记录缺省为枢府甜白与标准展厅。
- 挑战只比较轮廓吻合度，没有分阶段目标、排行榜与奖励；器型模板与三个挑战目标剪影数值一致，选模板即接近满分，属于演示便利而非难度设计。
- 音效由 Web Audio 现场合成，没有音频资产；无头环境静默降级，不参与验收断言。
- 未在真机（集显）上验证 60FPS 与内存预算；软件渲染 E2E 不构成该证据。

## 后续任务的拆分原则

一个Issue交付一个在当前页面可演示的增量，例如在现有画笔上增加橡皮擦；每次合并仍可完成整条创作路径。目录不是分工目标，用户行为才是验收对象。算法可先独立提交，但必须保留已有实现直到新实现集成可用。

## 验证范围

Vitest：轮廓合法性/单调样条采样、器型识别与造物参数、方位角与接缝、笔划合并、对称复刻与弦纹、撤销历史、印章几何与 `custom:` 轮廓编解码、图片轮廓提取、釉料与光照曲线、窑温遥测与开片网格、机位与排版、挑战评分、作品库读写与迁移（含可选的釉彩/灯光字段）；Playwright：实际调整半径、在3D表面落笔、撤销重做、橡皮擦只擦纹样、落印与缩放复位、彩绘阶段右键旋转、对称与弦纹落笔分布、名品快绘、名窑釉彩重开恢复、线框开关、器型挑战、烧制进度与一次性完成、导出PNG尺寸与排版、v1 存档迁移、刷新恢复、打开与删除。真实浏览器中验证，不以页面标题代替集成测试。除专门验证序幕的用例外，E2E 入口统一带 `?prologue=skip`。
