# 可运行基础版

此版本先提供可操作的集成起点，再拆分增量任务。启动、验证和AI执行规范见 [contribute.md](../contribute.md)。

## 已接通

八截面半径滑块控制真实 LatheGeometry；3D Raycaster 表面笔划与2048 CanvasTexture；双向U接缝拆分与笔刷边缘周期复制；绘制/旋转互斥；最近20步撤销重做且完整历史保留；2.5秒烧制遮罩、素坯/釉面参数切换；1080×1080 PNG；IndexedDB保存器型/全部有效笔划/成品图片，刷新后打开和删除。

## 明确的简化

- 轮廓为固定高度8点、线性采样；尚无二维点拖拽、样条和器型模板。
- 彩绘目前只有画笔、三个粗细和三种蓝色；尚无印章、橡皮擦和可撤销清空。
- 烧制是遮罩动画后切换材质，尚无PBR连续插值和精细环境贴图；机位为OrbitControls自由视角。
- 存储为 `StudioArtwork version:1`，数据库 `porcelain-tales-studio/artworks`；不是PRD目标ArtworkMetadata。当前图片是1080成品图，纹样通过完整strokes重放；迁移时不可把成品图当UV纹理。
- 暂无挑战和完整数据迁移/损坏记录恢复；不宣称达到60FPS/400MB或全部MVP0验收指标。

## 后续任务的拆分原则

一个Issue交付一个在当前页面可演示的增量，例如在现有画笔上增加橡皮擦；每次合并仍可完成整条创作路径。目录不是分工目标，用户行为才是验收对象。算法可先独立提交，但必须保留已有实现直到新实现集成可用。

## 验证范围

Vitest：轮廓合法性/采样、双向接缝、撤销后的历史分支；Playwright：实际调整半径、在3D表面落笔、撤销重做、烧制、读取导出PNG尺寸、保存、刷新恢复、打开与删除。真实浏览器中验证，不以页面标题代替集成测试。
