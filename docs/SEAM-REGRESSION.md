# 双向接缝回归（#21）

## 范围与复现

基于 main `d45b2e62a256b1f32ebcabeeee4a79179161da9d`，与 #34、#35 独立，不修改产品运行时。

```bash
npm ci
npx playwright install chromium
npm run check
npm run test:e2e -- tests/e2e/seam.spec.ts --workers=1
npm run test:e2e -- --workers=1
```

本轮环境（2026-11-09）：macOS Darwin 23.5.0 arm64，Node.js 22.14.0，Google Chrome 156.0.8078.81，1280×720，SwiftShader。系统 Chrome 可以由 PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH 指定。

## 断言依据

两个独立测试分别从左向右、从右向左拖动真实鼠标。由渲染帧的器身轮廓确定输入范围，不注入伪造动作，也不直接调用绘图算法。

- 在保存的真实动作中查找跨整数 U 的相邻点，确认确实跨过接缝。
- 检查方向和整体 U 跨度 <0.5，保持一笔。
- 从相邻点插值得到接缝交点 V，在实际 2048×2048 存档纹理的左右两侧各 3 列检查青花墨迹。
- 纹理中间（接缝对面的经线）不得有墨，防止错误贯穿整幅纹理；总墨迹必须大于 100 像素，避免空画面假通过。
- 绘制后撤销、重做，再烧制保存；刷新打开、继续彩绘、重新烧制保存，比较动作、纹理摘要和全部采样结果一致。
- 使用动作计数、保存状态及可观察页面元素等待，没有固定 sleep。Playwright 附件 seam-texture-evidence 保存每个方向的动作和像素统计。

## 限制

本次覆盖画笔与默认视角的双向接缝，不代表任意相机、橡皮擦或印章接缝均已验收。通过结果不证明真机性能达标；Viewport 卸载、Chrome/Edge 真机 FPS/内存等仍待验证，#21 保持开放。
