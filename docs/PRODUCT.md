# MVP0 需求基线

来源：用户指定的《产品需求与技术设计文档》，读取版本 2026-11-04。本文是实施摘要；需求变更先在 Issue 留下决定并同步原文档。

## 必须交付

- 首页：自由创作、主题挑战、本地画廊入口。
- 拉坯：6–10 控制点，归一化高度 [0,1]，半径 ≥0.08，相邻高度差 ≥0.05；64 段轮廓采样、48 径向段，实时光滑旋转体；重置/模板/参考线。
- 彩绘：2048×2048 单层 CanvasTexture，Raycaster 读取 UV；画笔/印章/橡皮擦互斥，粗中细 3 档和浓淡 3 档；缠枝莲/海水江崖/云纹 3 款透明印章；旋转与绘制模式互斥，20 步撤销重做。
- 烧制：交互锁定，素坯到高光白釉 PBR 渐变，结束自动进入成品页。
- 拍照：正视、俯仰 30°、特写和自由旋转，调光；导出 1080×1080 PNG，含名称、日期和印章。
- 归档：IndexedDB 保存作品、2048 纹理和图片，刷新后恢复；画廊查看/删除，存储失败可见。
- 挑战：玉壶春瓶、梅瓶、压手杯；目标剪影、0–100% 轮廓吻合度。

不实现：非轴对称、雕刻、多图层、已落笔元素二次变换、登录、服务端、云同步、移动端、外部图片上传、音效。

## 验收与人工性能测试

闭环流程和重载由 Playwright 验证；几何、UV 接缝、历史栈用 Vitest，核心算法 100% 覆盖率门槛。真实桌面 Chrome/Edge 上记录硬件和窗口尺寸：目标 60 FPS、几何更新 <16ms、峰值内存 <400MB、无 WebGL context lost。CI 软件渲染不替代集显实测。
