# 青花印章纹样来源

彩绘纹样库的缠枝莲、海水江崖、云纹、游鱼水藻、折枝石榴和折枝梅由本项目使用 OpenAI ImageGen 生成。提示词按这六种传统题材描述构图，以钴蓝浓淡、手绘笔触和透明留白表现青花。生成图转为透明 WebP 墨量遮罩，应用依照所选钴料颜色着色。素材存于 `public/images/stamps/`，生成输出依 OpenAI 适用条款使用。

以下为旧版矢量纹样的参考来源。器物实拍用于观察构图、线条和留白，未复制到印章素材。

| 纹样     | 器物实拍                                                                                                               | 重绘取材                                   |
| -------- | ---------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| 缠枝莲   | [明宣德青花石榴缠枝莲纹菊瓣碗（大都会艺术博物馆，1991.253.39）](https://www.metmuseum.org/art/collection/search/44745) | 内壁的层叠莲瓣、弧形蔓茎与回卷叶           |
| 海水江崖 | [明永乐青花海水纹香炉（故宫博物院，故00143416）](https://www.dpm.org.cn/collection/ceramic/227371.html)                | 炉腹尖峰、并行浪脊和上卷的浪花             |
| 云纹     | [清乾隆青花缠枝莲瓶（故宫博物院，新00041191）](https://www.dpm.org.cn/collection/ceramic/227703.html)                  | 瓶肩三瓣如意云头，改编为带云尾的独立纹样   |
| 游鱼水藻 | [明天启青花釉里红游鱼纹盘（大都会艺术博物馆，1984.360.1）](https://www.metmuseum.org/art/collection/search/50769)      | 盘心游鱼的叉尾和沿茎排列的细叶水藻         |
| 折枝石榴 | [明宣德青花石榴缠枝莲纹菊瓣碗（大都会艺术博物馆，1991.253.39）](https://www.metmuseum.org/art/collection/search/44745) | 碗心双果、冠形宿萼与露籽果实               |
| 折枝梅   | [清康熙青花冰梅纹罐（大都会艺术博物馆，79.2.265a, b）](https://www.metmuseum.org/art/collection/search/50919)          | 罐身的疏枝、五瓣梅花和放射花蕊，取花枝本身 |
| 回纹     | [明宣德青花石榴缠枝莲纹菊瓣碗（大都会艺术博物馆，1991.253.39）](https://www.metmuseum.org/art/collection/search/44745) | 碗口内沿的连续方折纹，展开成三节边饰       |

大都会艺术博物馆上述藏品的照片均标为 Public Domain，适用该馆的 [Open Access（CC0）政策](https://www.metmuseum.org/policies/image-resources)。故宫博物院藏品照片仅作视觉参考，未复制或随项目分发。

已保存作品中的 `lotus`、`seaside`、`cloud` 继续使用初版落印几何。六款生成纹样使用带 `-wash` 后缀的独立 ID。旧版六款矢量纹样及从纹样库移除的第 7 款回纹仍可按原 ID 重放。

## 名品快绘模版

三个模版参考大都会艺术博物馆的器物实拍。卡片复用器型百科已收录的 CC0 照片。落绘使用单独绘制的矢量色块，深浅分层叠染，部分闭合路径留出瓷白。细笔用来表现枝脉、鬃尾和箍线。
