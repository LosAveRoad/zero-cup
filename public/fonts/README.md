# Local font asset

`yan-zhen-qing-duo-bao-ta-bei.ttf` is a character subset of the font file
provided for this project: `YanZhenQingDuoBaoTaBei-2.ttf`. Its embedded metadata
identifies it as “Aa颜真卿多宝塔碑（非商业使用）”. The site uses it for headings
and keeps the supplied non-commercial-use restriction in view.

The font subset includes the characters used in the application. CSS requests
bold weight and synthesizes it from the provided regular font outlines. Body
text uses the site's original system font stack.
